Turn a vague prompt into a structured plan, a build output, and a refined final draft.

Interpreter

Extracts intent, constraints, domain, and execution steps from a messy prompt, then produces strict JSON for the next agent.

  • Identifies the real goal.
  • Normalizes domain tags.
  • Outputs actionable structure.

Constructor

Transforms the JSON into a first-pass MVP, choosing code or strategy based on the detected domain.

  • Generates the deliverable.
  • Prioritizes speed and clarity.
  • Stays aligned to the blueprint.

Optimizer

Critiques the draft against efficiency, profitability, and usability, then rewrites it to be production-ready.

  • Finds flaws fast.
  • Improves readability.
  • Adds practical polish.
